Parchly is a calm, native Markdown editor for your Mac. Write in a view that reads like a finished page, and your files stay plain Markdown on disk, exactly as you typed them. No library, no database, no account.

WRITE LIKE IT'S ALREADY FORMATTED
• Markdown syntax fades away as you read and comes back on the line you're editing
• Headings, bold, italic, strikethrough, code and links render inline
• Bullets, numbered lists and clickable task checkboxes
• Quotes, code blocks, rules and real table grids

NO SYNTAX REQUIRED
• A floating formatting bar puts every tool one click away: headings, bold, italic, lists, tasks, quotes, code, tables
• Every button has a keyboard shortcut for when you're ready
• A friendly guide opens on first launch

LISTS AND TABLES THAT KEEP UP
• Return continues a list, and Return on an empty item ends it
• Tab and Shift-Tab nest items, and numbered lists renumber themselves
• In tables, Tab moves between cells and tidies the source, and Return adds a row
• Paste a URL over selected text to make a link

SOURCE MODE AND LIVE PREVIEW
• Switch to plain monospaced Source with line numbers in one keystroke
• Open a side-by-side, GitHub-flavored preview with tables, task lists and footnotes

NOTES THAT LINK TOGETHER
• [[Wiki links]] and [[Note#Heading]] cross-references; ⌘-click to follow, or to create a note that doesn't exist yet
• Heading anchors and links within a page

MATH, DIAGRAMS AND CODE
• KaTeX math, Mermaid diagrams, GitHub alerts, highlights and emoji in the live preview
• Colour-coded code blocks

NINE THEMES
• Paper follows your Mac's light and dark appearance; or choose Warm Dark, Nord, Solarized, Sepia, Forest, Midnight or High Contrast

FIND AND PREVIEW YOUR FILES
• Quick Look extension: press Space on any .md file in Finder to see it rendered
• Go to File (⌘P) lists every Markdown file in the folder, with fuzzy search
• Go to Heading (⇧⌘O) jumps through your outline

A PROPER MAC APP
• Autosave, version history, tabs, and Rename and Move from the title bar
• If another app changes your file, Parchly reloads it
• Find & Replace, spelling, dictation and every standard text shortcut
• Export to PDF or HTML, or print
• Light, Dark or System appearance, and adjustable text size
• Keyboard shortcuts for every format, from ⌘B and ⌘K to ⌘1–⌘6 headings

PRIVATE BY DESIGN
Parchly collects no data, has no account and needs no internet connection. Your writing stays in your files.

Opens .md, .markdown, .mdown, .mkd, .mkdn and .mdwn files.
