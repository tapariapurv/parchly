**Parchly 1.1** is the first release under the new name. Inkdown is now **Parchly**, because another editor already used that name. It has a new icon, a redesigned interface, themes, a formatting bar, cross-linked notes, math and diagrams, and it now **updates itself**.

## Install

```sh
curl -fsSL https://tapariapurv.github.io/parchly/install.sh | bash
```

Or download **Parchly.dmg** below and drag it into Applications. On first launch, go to **System Settings › Privacy & Security › Open Anyway**. You only do this once.

> **Coming from Inkdown 1.0?** Run the command above once to switch over, then drag the old Inkdown app to the Trash. From now on Parchly keeps itself up to date.

## What's new

### ✨ A calmer, more polished design
- Downright-style document page: exact Paper Light / Warm Dark colours, serif type, generous rhythm, an H1–H6 badge beside the caret's heading, rounded checkboxes and inline code pills.
- **Liquid Glass** (macOS 26) on the toolbar, Document/Source switch, formatting bar and status pill.
- The new icon is a dog-eared parchment page.

### 🧰 Formatting bar: no syntax required
A floating bar with every tool: headings, bold, italic, strikethrough, inline code, link, bullets, numbers, tasks, quote, code block, table and divider. Show or hide it with ⇧⌘B.

### 🎨 Nine themes
Paper (follows light/dark), Paper Light, Warm Dark, Nord, Solarized Light, Solarized Dark, High Contrast, Sepia, Forest and Midnight. The preview follows your theme too.

### ⚙️ Settings (⌘,)
Theme swatches, text size, formatting bar, line numbers in Source mode (now **off by default**), spelling and update preferences.

### 🔄 Automatic updates
Parchly checks daily and installs signed updates in the background. **Parchly › Check for Updates…** checks right away.

### 🔗 Notes that link together
- `[[Note]]`, `[[Note|Label]]`, `[[Note#Heading]]` and `[text](#heading)` links.
- ⌘-click to follow a link. Links to notes that don't exist yet create them.

### 📐 Every Markdown element
- **Math** (`$…$`, `$$…$$`, KaTeX) and **Mermaid diagrams** in the preview, bundled for offline use.
- **GitHub alerts** (`> [!NOTE]`, `[!TIP]`, `[!WARNING]`…), `==highlights==`, `:emoji:`, setext headings and heading anchors.
- **Syntax-coloured code** in the editor, preview and Quick Look.
- **Images inline** in the editor, plus footnotes, reference definitions and HTML tags styled in place.

### ⌨️ Smarter typing
- Select text and type `*`, `_`, `` ` ``, `~` or `=` to wrap it.
- Brackets auto-close.
- Backspace inside an empty pair removes both halves.

### 🚀 Faster on big files
Typing in a 1 MB document dropped from about 50 ms to about 12 ms per keystroke.

### 📖 Built-in guide
A friendly getting-started note opens on first launch. Find it again under **Help › Markdown Guide**.

### 🧪 Tested
A new automated suite (`scripts/test.sh`) drives the real editor through:
- lists, tables, wrapping and auto-pairing
- undo and redo
- copy, cut and paste (including rich text and URLs)
- every format command
- round-trip fidelity and performance
