**Parchly 1.2.0** adds a Home window and a sidebar that's always there, makes tasks easier to type, and makes typing faster in long notes.

## Update
Parchly updates itself. Choose **Parchly › Check for Updates…** to get it now. New here?

```sh
curl -fsSL https://tapariapurv.github.io/parchly/install.sh | bash
```

## New
- 🏠 **Home**: start a new document, open one, make a note from the clipboard, open the guide, or pick a recent document. It shows at launch and when you close the last document, or press **⇧⌘H**. Drop Markdown files on it to open them.
- 🗂️ **Sidebar on by default**, with a toolbar button to hide it. For an unsaved note it lists your recent documents.
- ☑️ **Type `[]` and a space to start a task**. `[ ]`, `[x]` and `- []` work too, in both Document and Source mode. ⌘L and Task List also fix up lines written as `[ ] item`.

## Fixes
- ☑️ **Tasks look right everywhere**
  - In the preview, a task's text no longer drops below its checkbox in lists that have blank lines between items.
  - Wrapped task text lines up under the text, not under the box.
  - Strikethrough starts at the text, and sub-tasks under a done task aren't crossed out.
- ↩️ **Wrapped lines hang correctly in the editor** for tasks, bullets, numbered items and quotes in Source mode.
- 📊 **Table column alignment** (`:--`, `:-:`, `--:`) now shows in the editor, not just the preview.
- 🧭 **Jumping to a heading** from the outline, ⇧⌘O or a `#link` puts the caret after the hidden `##`, so typing doesn't edit the heading markers.
- 🎛️ **The formatting bar works even while the sidebar or Find field has focus.**
- ⇧ **Return** is no longer confused by Shift being held in another app.

## Faster
- Opening a saved file, switching Document/Source, or changing text size on a big note is about 11× faster (1 MB: 21 s → 1.9 s).
- First load of a 1 MB note went from 3.6 s to about 2 s.
- Typing in a 1 MB note went from 12 ms to 7 ms per keystroke, because only the visible text is laid out.
- A hidden preview is no longer re-rendered on every keystroke.

## Tested
- A new app-level self-test opens real documents and checks save, revert, the sidebar (listing, filters, new file), the outline, anchor and wiki links, pasted images, Find, modes, the preview, themes, every setting, Home, and new-from-clipboard.
- It also clicks every formatting-bar button and fires every menu command against a live document, and checks that each one undoes exactly.
- New editor checks cover clicking checkboxes and links, and measure the exact wrap indent of every list type.
