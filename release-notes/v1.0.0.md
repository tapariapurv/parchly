**Inkdown 1.0** is the first release of a calm, native Markdown editor for macOS. Write in a page-like Document view, flip to Source when you want the raw text, and press Space in Finder to preview any `.md` file. Your files stay plain Markdown on disk: no library, no database, no sidecar files.

## Install

**One line (recommended).** Paste into Terminal:

```sh
curl -fsSL https://tapariapurv.github.io/inkdown/install.sh | bash
```

This downloads the app below, puts it in Applications, turns on the Quick Look extension and opens Inkdown.

**Or download the DMG.** Open **Inkdown.dmg** and drag Inkdown into Applications. This build isn't notarized by Apple, so the first launch is blocked. Go to **System Settings › Privacy & Security**, click **Open Anyway** next to Inkdown, and confirm. You only need to do this once.

Requires **macOS 14 Sonoma or later**, on Apple silicon or Intel.

## What's in 1.0

### ✍️ Document mode
- Markdown syntax hides as you read and comes back on the line you're editing, so the file stays exact while the page looks finished.
- Headings in a serif type scale, with an **H1–H6 badge** in the margin beside the caret's heading.
- **Bold**, *italic*, ~~strikethrough~~, `inline code` and links render inline. ⌘-click opens a link.
- Bullets draw as • / ◦. **Task checkboxes** toggle with a click or ⌘L, and done items are struck through.
- Quotes get a tan margin bar. Code blocks get a soft panel. Rules draw as lines.
- **Tables** render as a real grid, with columns aligned however the source is spaced.

### ⌨️ Smart editing
- Return continues bullets, numbered lists, tasks and quotes. Return on an empty item ends the list, or outdents it if it's nested.
- Tab / Shift-Tab nest and outdent list items, and **numbered lists renumber themselves**.
- In tables, Tab / Shift-Tab move between cells and reformat the source, Return adds a row, and Return on an empty row leaves the table.
- Backspace right after a list marker or heading prefix removes it.
- Pasting a URL over selected text makes a link.
- Shortcuts for every format: ⌘B, ⌘I, ⇧⌘X, ⌃`, ⌘K, ⌘1–⌘6, ⌘0, ⇧⌘7/8/9, ⌥⌘Q, ⌥⌘C, ⌥⌘T, ⌘[ ⌘]. You can also move lines (⌃⌘↑/↓) and duplicate them (⇧⌘D).

### 🧾 Source mode & preview
- **Source mode** (⌃⌘2): plain monospace Markdown with line numbers.
- **Side-by-side preview** (⌘\\): GitHub-flavored rendering (cmark-gfm) with tables, task lists, footnotes and autolinks, scroll-synced to the editor.

### 🔎 Find your files
- **Quick Look extension**: press Space on any `.md` file in Finder to see it rendered.
- **Files & Outline sidebar**: ⌘P fuzzy-searches every Markdown file in the document's folder, ⇧⌘O jumps to any heading, and **+** creates a new file next to the current one.

### 🍎 A proper Mac app
- Autosave, Versions (browse and revert), and Rename / Move from the title bar. If another app changes the file, Inkdown reloads it.
- Tabs, Find & Replace (⌘F / ⌥⌘F), spelling, dictation and every standard text shortcut.
- Export to **PDF** or **HTML**, and Print.
- Light, Dark or System theme, plus text size controls (⌘= / ⌘- / ⌥⌘0).
- Opens `.md`, `.markdown`, `.mdown`, `.mkd`, `.mkdn` and `.mdwn`.

## Good to know
- If another app (such as Downright) also previews Markdown, choose Inkdown in **System Settings › General › Login Items & Extensions › Quick Look**.
- To open `.md` files with Inkdown by default, select one in Finder and choose **Get Info › Open with › Inkdown › Change All**.
- **Uninstall:** quit Inkdown and drag it from Applications to the Trash.
