**Parchly 1.1.2** fixes code blocks and links, and makes paste and drag-and-drop smarter. It's the result of a full stress-test pass.

## Update
Parchly updates itself. Choose **Parchly › Check for Updates…** to get it now. New here?

```sh
curl -fsSL https://tapariapurv.github.io/parchly/install.sh | bash
```

## Fixes
- 🧱 **Code blocks**
  - Typing at the end of an open code block no longer auto-pairs brackets or leaks indentation past the closing fence.
  - Press Return after ```` ```lang ```` and the closing fence is added for you.
  - Smart indentation after `{` `[` `(` `:`, and `{|}` expands onto its own line.
  - Tab inserts spaces in code.
  - Padding around the first and last lines of each code panel.
- 🔗 **Links look like links**
  - Links are always underlined (wiki links dotted), with a pointing-hand cursor.
  - In Document mode a plain click opens a link. ⌘-click works anywhere, including the line you're editing.
- 📋 **Paste & drop**
  - Files copied or dropped from Finder become Markdown links, and images become images, with paths relative to your note.
  - Pasting a screenshot or copied image saves it next to the note and inserts it. Parchly asks for folder access if needed.
- 📄 **Export**: exported HTML now typesets math and Mermaid diagrams.

## Tested
New automated checks cover:
- code blocks and link styling
- file, image, multi-line and 220 KB pastes
- exact undo for every format command
- Unicode, emoji and IME input
- a 500-step random fuzz in each mode that must never crash and must undo back to the original

A hands-on pass on a real Mac covered clicking links (with the folder-access prompt), the formatting-bar buttons, the preview (KaTeX, Mermaid), PDF/HTML export, and copying the whole document.
