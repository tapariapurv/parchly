**Inkdown 1.0.1** makes Inkdown sandboxed and Mac App Store ready, with no change to how you write.

## Install / update

```sh
curl -fsSL https://tapariapurv.github.io/inkdown/install.sh | bash
```

Or download **Inkdown.dmg** below and drag Inkdown into Applications. The build isn't notarized, so on first launch go to **System Settings › Privacy & Security › Open Anyway**.

## What's new
- 🔒 **App Sandbox.** Inkdown can now only touch the files and folders you open or allow, which is the same protection Mac App Store apps get.
- 📂 **One-click folder access.** The Files sidebar asks once ("Allow Access…") to list a folder's other Markdown files. Inkdown remembers that choice across launches and uses it to open relative links, create new files and show local images in the preview.
- 🖼️ **More reliable preview images.** Local images are served to the preview through a private `inkdown-file://` scheme instead of broad disk access.
- 🛡️ **Privacy manifest.** Inkdown declares that it collects no data and does no tracking. The privacy policy is at https://tapariapurv.github.io/inkdown/privacy.html.
- 💻 **Universal build** for Apple silicon and Intel.

## Notes
- Your settings start fresh after this update, because sandboxed apps keep preferences in their own container.
- Everything from 1.0 is unchanged: Document and Source modes, smart lists and tables, the live preview, and the Quick Look extension.
