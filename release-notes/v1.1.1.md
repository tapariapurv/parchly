**Parchly 1.1.1** is a small polish release, and the first one delivered by Parchly's new automatic updater.

## Install / update
If you have Parchly 1.1, it updates itself. You can also choose **Parchly › Check for Updates…**. New here? Run:

```sh
curl -fsSL https://tapariapurv.github.io/parchly/install.sh | bash
```
